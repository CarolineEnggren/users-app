# Users App

Users App is a React and TypeScript application created as an individual school project.

The application fetches user data from an external REST API and displays it across multiple views.

## Features

- Home page with user statistics
- User overview
- Individual user details
- Navigation with React Router
- Loading, empty and error states
- Retry functionality for failed API requests
- Global Error Boundary for unexpected rendering errors
- Responsive design

## Technologies

- React
- TypeScript
- Vite
- React Router
- TanStack React Query
- Tailwind CSS
- Lucide React
- react-error-boundary
